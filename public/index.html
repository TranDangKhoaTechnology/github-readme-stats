API có sẵn

Các endpoint dưới đây đều được tạo từ chính deployment hiện tại.

📊 Stats

Commits, stars, PR, issues, reviews và các chỉ số mở rộng.

/api?username=...

🧠 Languages

Top ngôn ngữ với compact, donut, donut-vertical, pie.

/api/top-langs?username=...

📌 Repo Pin

Card cho repository với mô tả, stars, forks và language.

/api/pin?username=...&repo=...

🧩 Gist

Hiển thị một GitHub Gist bằng ID.

/api/gist?id=...

⏱ WakaTime

Dùng WakaTime username riêng và yêu cầu profile/code stats public.

/api/wakatime?username=...

CacheCards có cache để giảm GitHub API calls. Không nên ép refresh liên tục nếu không cần thiết.
